## 6. The five most consequential one-sided REALs

### 6.1 OLD-only (redo missed all five; all adjudicated REAL at the pin)

1. **PS2SERVERS-059 — srvsvc `auth_len` slice wrap.** `smb2_srvsvc.py:152`: when `auth_len > frag_len − 16` the body slice `data[16:frag_len-auth_len]` wraps negative and the BIND_ACK is built from bytes past the declared PDU. Executed: control `auth_len=0` → clean `RpcError`; `auth_len=200, frag_len=28` → 68-byte BIND_ACK, `bound=True`. A wire-reachable parser memory-safety defect in the SMB2 RPC layer.
2. **PS2SERVERS-115 — the embedded SMB2 header is 66 bytes, not 64.** Executed: `calcsize("<4sHHIIHIIQQQ16s") == 66`; `pack_smb2_hdr` emits 66 bytes while declaring StructureSize 64, and `Smb2Req` rejects a correct 64-byte header. The SMB1 file's embedded SMB2 speaks a header no real SMB2 peer emits.
3. **PS2SERVERS-066 — launcher block devices assign seek state before validating it.** Executed with the filed numbers: a failed RawDevice seek leaves `_position=51200, _request_end=51251200` and the next read returns stale cache bytes (0x07) with zero backend reads; VirtualExfat serves 512 gap-fill bytes past end. Silent data corruption on the image-serving path.
4. **PS2SERVERS-067 — AES-CMAC native fallback is probe-time-only.** `smb2_crypto.py:124-129` calls the probed native backend unconditionally thereafter; executed: a seeded mid-session native failure raises `OSError` out of `signed()` (smb2_server.py:492), escapes the dispatch mapping, and drops the connection — instead of falling back to the pure-Python CMAC in the same file.
5. **PS2SERVERS-023 — the combined default posture.** SMB1 guest-accepted + writable by default (`smbserver_opl.py:14, :739-751, :1684-85`), SMB2 `open_share` "anyone on the network can read it", NFS no password, HTTP no auth, UDPFS unauthenticated sessions — filed by the old corpus as one systemic mechanism with one fix direction. 1. **RE-SERV-001 — SMB2 signing downgrade.** Pre-authentication commands stay live after authentication: an unsigned mid-session NEGOTIATE/SESSION_SETUP clears the signing key while the session stays authenticated (smb2_server.py:537-538, :855-856; negotiate-claims overwrite :745-755).
