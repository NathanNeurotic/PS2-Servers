# Build-only dependencies for the 32-bit Windows package (PS2Servers-windows-x86),
# which is built with Python 3.8 so it runs on Windows 7 and 8 (issue #330).
#
# Python 3.9 and later cannot start on Windows 7: python39.dll and newer import
# api-ms-win-core-path-l1-1-0.dll, and python312.dll also imports
# kernel32!PssQuerySnapshot (Windows 8.1). Python 3.8.10 is the last official
# CPython with a Windows installer that runs on Windows 7 SP1.
#
# Same packages as requirements-build.txt, at the newest release of each that
# still supports Python 3.8. tools/check_win7_imports.py checks the result.
#
# Dependabot must never bump this file: every newer zstandard, lz4 and Pillow
# drops Python 3.8, so a bump here can only break the Windows 7 package (#332
# was one). .github/dependabot.yml has an entry for /build that ignores every
# dependency, for version and security updates alike. Bump by hand, and only to
# a release that still ships Python 3.8 wheels. Nuitka is bumped by hand too,
# after checking the new release still supports Python 3.8; the "Windows 7
# package" workflow builds and checks the result on the pull request.

Nuitka==4.3.5
ordered-set==4.1.0
zstandard==0.23.0
lz4==4.3.3
Pillow==10.4.0
