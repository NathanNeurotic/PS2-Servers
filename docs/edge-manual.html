Edge Operator Manual

Complete operational handbook for ps2servers-edge, detailing command-line options, security modes, and configuration parameters across all four subcommands.

Invocation Model
Edge operates on a one-command-per-process model. To run multiple services concurrently (e.g. UDPFS and the Web UI), invoke each as a distinct background daemon or systemd / procd service.

1. Subcommand: udpfs

Serves a games directory tree and optional block devices over the UDPFS protocol.

ps2servers-edge udpfs --root /srv/ps2 [flags]
Flag Default Description
--root PATH (Required) Root folder holding your DVD/ and CD/ collections.
--bind IP 0.0.0.0 Local IP address to bind both discovery and data sockets.
--port PORT 62966 Discovery UDP port (standard is 62966 / 0xF5F6).
--data-port PORT 0 (dynamic) Pin a dedicated data port (e.g. 62967) for restrictive firewall policies.
--single-port false Serve both discovery and data out of the single primary UDP port.
--protocol-mode auto Negotiation mode: auto, standard, or modulo.
--peer-timeout 1h Inactivity duration before closing peer handles (accepts 1m to 24h).
--read-only false Disallow console file modifications (saves/configs).
--no-compression false Diagnostic flag: expose raw compressed containers without decoding.
--metrics false Log periodic transfer rate statistics to stdout.

2. Subcommand: smb

Serves guest-authenticated SMBv1 shares for standard OPL clients.

ps2servers-edge smb --share games=/srv/ps2 --port 1111 [flags]
Flag Default Description
--share NAME=PATH — Define a share name and target path. May be repeated for multiple shares.
--root PATH — Shorthand alias defining the games share directly.
--port PORT 1111 TCP listening port. Configure your loader to match this number.
--read-only false Prevent writes to the share from connected clients.
--status-port PORT -1 (62966) UDP port for router status discovery replies. Set to 0 to disable.

3. Subcommand: udpbd

Serves one disc image as a raw block device over UDP port 48573.

ps2servers-edge udpbd --image /srv/images/game.iso --read-only [flags]
Flag Default Description
--image PATH (Required) Path to the target .iso or raw disc image.
--port PORT 48573 UDPBD listening port (default 48573 / 0xBDBD).
--bind IP 0.0.0.0 Bind address on the host system.
--read-only false Prevent raw block write requests from modifying the backing image.

4. Subcommand: webui

Starts the embedded web management dashboard.

ps2servers-edge webui --bind 0.0.0.0 --auth-pass 'mypassword' [flags]
Flag Default Description
--bind IP 127.0.0.1 Listening address. Use 0.0.0.0 to access from other LAN devices.
--port PORT 8082 HTTP web server port.
--auth-pass PASS (Required for 0.0.0.0) Password required to authenticate in the browser dashboard.
--insecure false Auto-generates a temporary random password if none is supplied.
--browse-anywhere false Permit directory navigation outside configured game directories.
--no-browse false Completely disable the file browser view in the web dashboard.

5. Inspecting the Configuration Contract

Edge provides a built-in schema dumper to assist with configuration automation, OpenWrt LuCI generation, and container orchestration:

ps2servers-edge --dump-schema
