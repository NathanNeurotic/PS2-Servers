Download verification

Antivirus and trust

PS2 Servers is an unsigned, open-source network utility. Its packaging and server behavior can trigger heuristic detections. A detection name alone does not establish whether a file is safe or malicious.

Full transparency guide Official releases

Portable and single-file downloads

The Windows portable archive contains the executable and its libraries in a folder. It avoids the single-file self-extraction wrapper, but remains unsigned and can still be flagged. Keep the complete extracted folder together.

Use the release’s download table for your OS and architecture. Windows has x64 and x86 builds; Linux has x64 packages; macOS has Intel and Apple Silicon packages. Edge is a separate headless executable. Availability depends on the assets that successfully built for that release.

Nuitka single-file packages extract and re-execute on launch. That behavior, an unsigned executable, and listening on network ports can contribute to detections; none of those facts verifies an individual downloaded file.

Verify the exact file

  1. Download from the project’s GitHub release and record its tag/commit and asset name.
  2. Compare SHA-256 against that release’s SHA256SUMS.txt, Desktop .sha256.txt sidecar, or Edge .sha256 sidecar.
  3. Verify a published artifact attestation using the filename you downloaded.
gh attestation verify PS2Servers-windows-x64-portable.zip -R NathanNeurotic/PS2-Servers

Checksums verify integrity and attestations verify build provenance. Neither proves safety or console compatibility. Inspecting and running/building from source is another option. Code signing would not guarantee the absence of detections either.

Expected behavior

LAN servers

SMBv1 uses TCP 1025 by default in Desktop and 1111 in Core/standalone or Edge, SMB2/3 TCP 1445, HTTP game serving TCP 1100, UDPFS UDP 62966 plus a data socket, and UDPBD UDP 48573. Edge’s optional management dashboard uses TCP 8082 and requires a password for LAN access.

Windows setup

The app does not enable Windows SMB1 or change Windows optional features. Firewall changes need user action/consent and use PS2 Servers - ... rules. Optional Take port 445 temporarily stops Windows File Sharing. Direct-link setup changes a dedicated interface and serves DHCP; both require elevation.

Saved configuration

The launcher saves per-user settings, which may include SMB2/3 credentials. Auto-start servers on launch applies when the app opens; it does not create an OS login task. Manually installed services are persistent until removed. Source-mode dependency installation can contact a package index after confirmation.

The project does not add advertising, browser extensions or crypto-mining. Edge offers optional remote service management with authentication and host permissions, as described in the full transparency guide.

Before removing the app, stop servers and disable direct link to restore its temporary network changes. Then remove the app folder, optionally its per-user settings, and its firewall rules. Manually installed services/containers need separate cleanup. See Security and cleanup.

Report a detection

Keep protection enabled while you verify the file. Include the release/commit, asset name, SHA-256, antivirus product/version, full detection name and any vendor report URL. Submit the application sample to the detecting vendor’s review process; do not upload games, saves or private credentials.
