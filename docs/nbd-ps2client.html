Planned Features: NBD & ps2client

Architectural vision for extending PS2 Servers with Network Block Device (NBD) capabilities and ps2client developer instrumentation.

Roadmap Feature
This specification defines planned integrations currently undergoing prototyping and architectural evaluation.

1. The Two Directions of NBD

The standard Linux Network Block Device (NBD) protocol enables block devices to be served over TCP port 10809. Within the PS2 ecosystem, this serves two transformative workflows:

Direction 1: PS2 HDD Export to PC (Internal HDD Management)

The PS2 console boots a dedicated NBD server ELF, exposing its internal APA / exFAT 3.5" or 2.5" hard drive over Ethernet. A PC mounts the PS2's internal drive as a native block device using WinNBD (Windows) or nbd-client (Linux).
Key Benefit: Allows users to copy ISOs, manage partitions, and backup saves at full 100Mbps Ethernet speeds without ever having to physically unscrew the network adapter or risk damaging 24-year-old IDE/SATA connector pins.

Direction 2: PC Block Image Export to PS2

PS2 Servers serves raw disc images and virtual drives over standard NBD (TCP 10809) as an alternative to UDPBD. Loaders with an NBD client driver mount remote PC storage directly with TCP flow control.

2. ps2client Integration

ps2client is the standard CLI utility for communicating with ps2link over Ethernet for homebrew developers. Integrating ps2client into the PS2 Servers Desktop launcher will allow:

  • One-click remote execution of ELFs directly on the console over LAN.
  • Live in-app streaming of PS2 kernel `printf` debugging logs (TTY output).
  • Remote console reboot and power management.
