HTTP Game Streaming

HTTP Mode serves your PS2 game collection over standard plain HTTP for compatible OPL forks (such as Docmine17's Open-PS2-Loader-HTTP and RiptOPL). By replacing SMB with standard HTTP Range requests, it eliminates complex network authentication entirely.

Experimental Status
HTTP game serving is host-tested and functional across compliant clients. Because loader support across diverse hardware remains under active community development, report findings to the project issue tracker.

1. Setting Up HTTP Mode

Start the HTTP Server Card

Select your games folder (the parent holding DVD/ and CD/) and start the HTTP card. The default port is TCP 1100.

Configure Your Console Loader

In OPL Network Settings, configure the following values:

Field Required Value
Protocol HTTP
Address Type IP
PC IP Address IP address shown on the running HTTP card
Port 1100 (Must be set explicitly)
Share Name Blank, or anything (ignored by server)
Critical Client Quirk: Set Port Explicitly
In the pinned Docmine17 HTTP client, leaving Port set to 0 causes its game-list loader to default to port 8080 while its in-game driver defaults to port 1100! The result is that your game list populates, but selecting a game produces an immediate black screen. Always set Port to 1100 explicitly in your loader.

2. What the Server Serves

The HTTP server inspects your games folder root, DVD/, and CD/, automatically generating two resources:

  • games.csv — Generated on the fly at /games.csv and /<share>/games.csv. Lists startup identifiers, titles, and media types without manual curation.
  • Bare Game ISOs: Disc images are flattened at the web root (e.g. GET /SLUS_201.74.Rumble Racing.iso) to accommodate the console driver's hardcoded root path.

3. Compressed Format Streaming

Format Handling Mechanism
.iso Streamed directly via HTTP Range headers.
.zso, .ziso Streamed compressed as-is. The PS2 client decompresses LZ4 blocks locally.
.chd, .cso Decompressed in real time on the server and advertised to the client as standard .iso.

4. Known Limits & Specifications

  • Read-Only Protocol: The HTTP client driver does not support WebDAV or HTTP PUT; Virtual Memory Cards (VMC) cannot be written over HTTP. Saves require a physical memory card.
  • No Authentication: Never expose port 1100 to the public internet; keep it strictly on your local private subnet.
  • Single-Layer Discs Only: The client driver hardcodes layer1_start = 0, so dual-layer DVD9 titles will not transition beyond the layer break.
  • Game List Buffer Limit: The console's receive buffer for games.csv is 8192 bytes (approximately 80–100 titles). Libraries exceeding this count should be categorized or curated.
