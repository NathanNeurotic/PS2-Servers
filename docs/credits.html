Credits, Sources & Acknowledgments

PS2 Servers is built on the collective achievements, reverse engineering efforts, and code contributions of the PlayStation 2 homebrew development community.

Core Contributors & Collaborators

NathanNeurotic (Ripto)

Creator and maintainer of PS2 Servers (Desktop, Core, Edge), the RiptOPL loader fork, and comprehensive PlayStation 2 documentation systems.

FatBaldDad

Author of PS2-EtherDrive. In direct collaboration, co-architecting unified server foundations, networking standards, and hardware testing methodologies.

Upstream Projects & Specifications

pcm720

Pioneer of the udpfsd protocol specification and original server implementation, establishing high-speed UDP-based network game loading on the PS2.

ps2homebrew Team

The maintainers of the canonical Open-PS2-Loader repository and the open-source ps2sdk toolchain.

darkladark (dnunezx)

Author of LUNA (Lightweight Unified Neutrino Access) and key contributor to Neutrino network loading, Modulo protocol integration, and RiptOPL improvements.

Docmine17

Creator of Open-PS2-Loader-HTTP, introducing ISO streaming via standard HTTP Range headers.

Maximus32

Creator of the modular Neutrino external game loader core and driver architecture.

uyjulian

Longtime contributor to OPL network drivers, lwIP integration, and high-performance SMB protocol improvements.

Open-Source Technologies

  • Python Software Foundation — Python 3 runtime and Tkinter GUI engine.
  • Go (Golang) Project — High-concurrency static binary compilation for Edge.
  • OpenWrt Project — Embedded Linux router operating system and package ecosystem.
  • libchdr — Fast, portable CHD compressed disc image decoding.
  • maxcso & LZ4 — High-speed compressed ZSO disc image containers.
