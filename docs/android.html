PS2 Servers for Android

Run all seven PS2 Servers protocols natively on any Android 5.0 (API 21) or newer phone or tablet over home Wi-Fi, hotspot, or USB-Ethernet tethering, and share Mobile Data internet with your PlayStation 2.

Download PS2Servers-android.apk Mobile Data Internet Setup
Validation Status
All seven protocol servers, Storage Access Framework adapters, and NAT/redirect helpers are host unit-tested on JVM and Android Lint verified for API 21–35. Real Android hardware and physical PlayStation 2 testing are still pending.

1. Download & Install

Download PS2Servers-android.apk from the Downloads & Releases page. It is a pure-Kotlin universal APK supporting ARM64, ARMv7, x86, and x86_64 phones and tablets running Android 5.0 or newer, with zero telemetry.

# Verify SHA-256 and GitHub build provenance before installing
sha256sum -c SHA256SUMS.txt --ignore-missing
gh attestation verify PS2Servers-android.apk -R NathanNeurotic/PS2-Servers

Tap the APK on your phone (allowing unknown apps when prompted) or install over USB debugging with adb install -r PS2Servers-android.apk.

2. Shared Games Folder (SAF & Fallback)

  1. Tap Choose Folder (SAF) to grant persistent access via Android's Storage Access Framework to the parent folder containing your uppercase DVD/ and CD/ directories.
  2. If your device uses a direct path, enter it under Fallback path or tap Use App Folder to serve files placed in the app's media directory.
  3. CSO / ZSO compression is enabled on UDPFS and HTTP by default and optional on SMBv1. CHD requires Desktop or Core.
  4. UDPBD automatically serves your Games Folder as a Virtual exFAT drive, or lets you pick a single raw .iso / .img file.

4. Home Wi-Fi LAN & Background Locks

When your phone connects to your home Wi-Fi and the PS2 connects to the same router over Ethernet, both sit on the same LAN subnet. Disable AP Isolation / Client Isolation on your router and stay off Guest Wi-Fi networks so Ethernet-to-Wi-Fi traffic and UDP discovery broadcasts pass freely. Starting any server launches a foreground service holding a PARTIAL_WAKE_LOCK, a low-latency WifiLock, and a MulticastLock (when UDPFS or UDPBD is active).

5. Connecting the PS2 to Mobile Data Internet

The PS2 Internet (Mobile Data) card helps you bridge cellular internet to your PlayStation 2 for DNAS and community online servers while simultaneously serving games locally.

Option A: Unrooted Android 11+ (USB-Ethernet Tethering)

  1. Connect a USB-Ethernet adapter to your phone and wire an Ethernet cable to the PS2.
  2. Tap Open Hotspot & Tethering and enable Ethernet tethering.
  3. In PS2 Network Config (NETCNF), choose Auto (DHCP), or enter the static IP, Subnet Mask, Gateway, and Primary DNS shown live in the app.

Option B: Unrooted Android 5.0+ (Wi-Fi Hotspot + Bridge)

  1. Enable Android's Wi-Fi Hotspot and join it from a travel router or Wi-Fi-to-Ethernet bridge connected to your PS2.
  2. Tap Refresh in the app to read the hotspot gateway IP and suggested PS2 static configuration.

Option C: Custom PS2 DNS & Root NAT Bridge

Enter a community revival DNS IPv4 under Custom PS2 DNS to update the NETCNF hints immediately. On rooted devices (including Android 5–10 with USB-Ethernet OTG), switch on Root NAT Bridge to enable IPv4 forwarding, iptables MASQUERADE to your active cellular interface, and optional TCP/UDP port 53 DNS redirection.

6. Quick Troubleshooting

  • No incoming connection on Wi-Fi: Confirm the phone is on the main SSID (5 GHz recommended) rather than a guest network, and check the top Device IP banner.
  • Loader hardcodes SMB port 445 on unrooted Android: Switch to UDPFS (62966), HTTP (1100), NFSv4 (2049), or UDPBD (48573).
  • Background drops: Allow notifications on Android 13+ and exclude PS2 Servers from aggressive OEM battery optimization if your device vendor kills foreground services.
