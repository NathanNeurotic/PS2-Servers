Downloads & Releases

Official release binaries for Windows, Linux, macOS, and embedded architectures. PS2 Servers binaries are compiled directly from source in automated GitHub Actions workflows with cryptographic attestations.

Pre-Releases vs Tagged Releases
For active development and the latest compatibility improvements (such as UDPFS handoff resilience and Edge Web UI updates), download the newest pre-release on GitHub. A tagged release may represent an earlier milestone. Always inspect the assets table of the release for the exact packages built.

Desktop & Workstation Packages

Desktop packages include the Tkinter graphical launcher, the underlying Core CLI, and all server modules. Portable builds keep all libraries extracted in a folder and avoid single-file decompression overhead.

Platform Recommended Package Alternative / Legacy Description

Verifying Checksums & Build Attestations

Integrity can be confirmed against the published SHA-256 checksums, and cryptographic build provenance can be verified via the GitHub CLI:

# 1. Verify SHA-256 on Linux/macOS
sha256sum -c SHA256SUMS.txt

# 1b. Verify SHA-256 in Windows PowerShell
Get-FileHash .\PS2Servers-windows-x64-portable.zip -Algorithm SHA256

# 2. Verify GitHub Actions build attestation
gh attestation verify PS2Servers-windows-x64-portable.zip -R NathanNeurotic/PS2-Servers
Antivirus Detections on Windows
Unsigned executables that bind to network sockets and extract self-contained runtime files are commonly flagged by heuristic antivirus scanners. These are false positives. See our complete Antivirus Transparency & Trust Guide for detailed analysis and exclusion instructions.
