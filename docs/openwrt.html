OpenWrt Router Setup

Turn your home router into a dedicated, 24/7 PlayStation 2 game server. By running PS2 Servers Edge directly on OpenWrt with a USB storage drive, you can play your entire library over Ethernet with zero PC running.

Why an OpenWrt Router Server?
Home routers are always powered on, consume less than 5 Watts of electricity, and feature direct gigabit/fast Ethernet switching to your entertainment center. Edge requires under 20 MB of RAM, leaving plenty of headroom for normal routing and Wi-Fi duties.

1. Prerequisites

  • A home router running modern OpenWrt (version 21.02, 22.03, 23.05, or newer).
  • A USB 2.0 or USB 3.0 port on the router.
  • An external USB flash drive, external SSD, or HDD formatted in ext4, exFAT, or FAT32.
  • Free internal flash storage (approximately 6–10 MB) to install the package.

2. Mounting USB Storage on OpenWrt

Log in to your router via SSH and install the necessary filesystem kernel modules:

# Update package list and install storage drivers
opkg update
opkg install kmod-usb-storage block-mount kmod-fs-ext4 kmod-fs-exfat kmod-fs-vfat e2fsprogs

# Identify your connected USB drive partition
block info

Create a mount point (e.g. /mnt/ps2games) and enable auto-mounting via /etc/config/fstab or the LuCI web interface under System → Mount Points.

3. Installing the PS2 Servers Edge Package

Download the .ipk package matching your router's architecture (e.g. mipsel for MT7621, mips for ath79, or aarch64 for modern ARM routers) from the Releases page:

# Transfer package to router /tmp folder via scp, then install:
opkg install /tmp/ps2servers-edge_*.ipk

4. Configuring via UCI (/etc/config/ps2servers)

The package ships with an integrated OpenWrt UCI configuration file. Edit /etc/config/ps2servers:

config ps2servers 'global'
    option enabled '1'
    option root_dir '/mnt/ps2games'
    option read_only '1'

config service 'udpfs'
    option enabled '1'
    option port '62966'
    option protocol_mode 'auto'

config service 'smb'
    option enabled '1'
    option port '1111'
    option share_name 'games'

config service 'webui'
    option enabled '0'
    option port '8082'
    option auth_pass 'changeme'
Default Security Profile
On OpenWrt, PS2 Servers Edge ships with read_only set to 1 and the Web UI disabled by default to preserve router flash and protect against accidental corruption. Adjust these options in UCI according to your operational needs.

5. Service Control & Monitoring

Manage the server via OpenWrt's native procd init system:

# Enable service to start on router boot:
/etc/init.d/ps2servers enable

# Start the service immediately:
/etc/init.d/ps2servers start

# Check service status:
/etc/init.d/ps2servers status

# View live connection logs from your PS2:
logread -e ps2servers -f

6. Connecting From the PS2

Because the router itself is hosting the server, point your loader's PC IP setting directly to your router's LAN gateway address (commonly 192.168.1.1):

  • SMBv1: IP 192.168.1.1 · Port 1111 · Share games · User guest
  • UDPFS: IP 192.168.1.1 · Port 62966 · Auto Mode
