Which PS2 Servers Edge Build Do I Need?

Edge provides compiled native binaries for virtually every CPU architecture in existence. Use this quick reference to choose the exact binary for your server device.

Quick Advice for Standard PC Users
If you are running Linux on an ordinary 64-bit PC, mini PC, Intel/AMD NAS, or Proxmox VM — download pc-64bit-amd64 and you are done.

1. The 30-Second Answer

Log in to a terminal on the device that will host your games (e.g. via SSH) and run:

uname -m

Match the terminal output to the table below:

uname -m Output Download Package Suffix Common Hardware Examples
x86_64 pc-64bit-amd64 Modern PCs, mini PCs (Beelink, Intel NUC), Intel/AMD NAS (Synology, QNAP)
i386, i486, i586, i686 pc-32bit-i386 Legacy 32-bit PCs, early Intel Atom netbooks, older thin clients
aarch64 or arm64 arm64-pi3-pi4-pi5-nas Raspberry Pi 3/4/5 on 64-bit OS, modern ARM NAS, newer 64-bit routers
armv7l armv7-pi2-32bit-routers Raspberry Pi 2, Pi 3/4/5 running a 32-bit OS, 32-bit ARM routers
armv6l armv6-pi1-pi-zero Raspberry Pi 1, Raspberry Pi Zero, Pi Zero W
armv5tel or armv5tejl armv5-pogoplug-sheevaplug-dockstar Pogoplug, SheevaPlug, Seagate DockStar, Kirkwood NAS appliances
mips See MIPS Endianness below Most classic home routers (OpenWrt, DD-WRT)
mips64 edgerouter-octeon-mips64 Ubiquiti EdgeRouter Lite, EdgeRouter PoE, EdgeRouter 4, EdgeRouter 6P
riscv64 riscv64-sbc StarFive VisionFive 2, Milk-V Mars, Sipeed LicheeRV
Raspberry Pi Trap: Always Check uname -m
Do not assume your Pi OS is 64-bit just because the hardware is a Pi 4 or Pi 5! If you installed the standard 32-bit Raspberry Pi OS image, uname -m outputs armv7l and you must download the armv7 package. Running the arm64 binary on a 32-bit kernel will result in an immediate Exec format error.

2. MIPS Routers: Big-Endian vs Little-Endian

The command uname -m outputs mips for both big-endian and little-endian hardware. To determine the correct binary on OpenWrt:

opkg print-architecture
  • If the output contains mipsel_... (notice the el): your device is Little-Endian.
    → Download router-mips-little-endian-mt7621 (Common for MediaTek MT7621, ramips routers).
  • If the output contains mips_... (without el): your device is Big-Endian.
    → Download router-mips-big-endian-ath79 (Common for Qualcomm/Atheros ath79, TP-Link, Netgear).

3. Troubleshooting Execution Errors

"cannot execute binary file" or "Exec format error"

This error signifies an architecture, endianness, or ABI mismatch. Re-verify uname -m and your C-library/kernel architecture. Trying the alternate MIPS binary is completely harmless.

"Permission denied"

Ensure execute permissions are granted after downloading onto Linux or router storage:
chmod +x ./ps2servers-edge
