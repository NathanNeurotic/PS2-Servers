SMB Server (v1 / v2 / v3)

Server Message Block (SMB) remains the standard network sharing protocol for Open PS2 Loader (OPL) and RiptOPL. PS2 Servers provides user-space SMBv1, SMB2, and SMB3 server engines that eliminate the need to enable obsolete or insecure Windows OS features.

Dialect Rule: Choose What Your Loader Supports
An SMBv1-only loader cannot connect to an SMB2/3 server simply because both cards point to the same games folder. You must run the server dialect matching your loader's network driver.

1. SMBv1 for Traditional OPL Clients

Standard OPL releases use SMBv1 (dialect NT LM 0.12). Modern operating systems (Windows 10/11, macOS, and current Linux distributions) have disabled SMBv1 by default due to security vulnerabilities in Microsoft's kernel SMB1 driver (such as EternalBlue).

PS2 Servers solves this safely: our SMBv1 engine runs entirely in unprivileged user-space on a non-standard port. It does not enable Windows' SMB 1.0 optional feature, does not touch kernel drivers, and leaves your standard Windows File Sharing untouched.

Entry Point Default TCP Port Default Share Name Default Credentials
Desktop SMBv1 Card 1025 games User: guest · Pass: (blank)
Core CLI (serve smbv1) 1111 games User: guest · Pass: (blank)
Edge Go Server (smb) 1111 games User: guest · Pass: (blank)
OPL Console Configuration for SMBv1
In your loader's Network Settings:
  • Address type: Set to IP (do not use NetBIOS name).
  • IP address: Enter the PC LAN IP shown by the server (e.g. 192.168.1.100).
  • Port: Set to 1025 (Desktop) or 1111 (Core/Edge).
  • Share name: Enter games.
  • User: guest · Password: (leave empty).

2. SMB2 and SMB3 Authenticated Sharing

For modern OPL forks (such as RiptOPL with SMB2 support enabled in Game Sources), PS2 Servers includes authenticated SMB2 (up to dialect 2.1) and SMB3 (up to dialect 3.0.2) server cards.

SMB2/3 Parameters

  • Default Port: TCP 1445 (distinct from standard 445).
  • Username: Default ps2 (configurable).
  • Password: Configurable private password.
  • Open Share Mode: Checking No password (anyone on the network can read it) removes password authentication while retaining SMB2/3 packet framing.
Take Port 445 (Admin Option)
Windows File Explorer connects only to TCP 445. The optional Take port 445 (admin) toggle in Desktop attempts to temporarily stop the Windows Server service to free TCP 445. For ordinary PS2 gaming, this is unnecessary: configure your loader with port 1445 instead.

3. Writes & Virtual Memory Cards (VMC)

Both SMBv1 and SMB2/3 in PS2 Servers allow write access by default:

  • Virtual Memory Cards: Loaders can create and update 8MB .bin files in the VMC/ folder directly over the share.
  • Per-Game Configuration: Settings saved in OPL are written back to CFG/ automatically.
  • Read-Only Mode: Ticking Read-only prevents any modifications to the games directory, safeguarding against accidental file tampering.
LAN Security Reminder
Never forward SMB ports (1025, 1111, 1445, or 445) across your internet router. These servers are designed strictly for private Local Area Networks.
